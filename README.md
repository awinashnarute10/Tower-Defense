# Retro Tower Defense

A pixel-art, arcade-style Tower Defense game — React 19 + Vite + a hand-rolled
Canvas2D game engine, no game framework, no backend.

- **[GAME.md](GAME.md)** — how to play: controls, towers, enemies, waves, tips.
- **[ARCHITECTURE.md](ARCHITECTURE.md)** — how it's built: engine/rendering
  architecture, game loop, performance optimizations, benchmarks, deployment.

## Quick start

```bash
npm install
npm run dev       # http://localhost:5173
```
